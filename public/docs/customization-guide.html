Customization & Telegram CMS Guide

This website is built to be managed easily from your phone via Telegram or from your local machine via the .env file.

1. Setting Up Telegram CMS

  1. Open Telegram and message @BotFather to create a new bot (run /newbot).
  2. Copy the HTTP API Token provided by BotFather.
  3. Message @userinfobot in Telegram to get your numeric Chat ID.
  4. Open your .env file and add: 
    BOT_TOKEN=your_token_here
CHAT_ID=your_numeric_chat_id
  5. Double-click deploy.bat to upload your secrets and activate your webhook automatically!

2. Telegram Bot Commands

  • /start: Main admin control menu.
  • /add_note: Send any document, PDF, or text note to publish instantly.
  • /stats: Check real-time site visitor metrics.
  • /announce: Set or update the live notification banner on your website.

3. Managing Inquiries & Q&A

When a visitor fills out the contact form on your site, you will receive an alert on Telegram with a unique inquiry ID. Simply reply directly to that message on Telegram to respond or publish the answer!
